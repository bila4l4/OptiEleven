# Code of conduct

OptiEleven follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and patient, assume good faith, and keep discussions about the project. Harassment, insults, and personal or political attacks are not accepted, in issues, pull requests or anywhere the project is represented.

## Reporting

If someone breaks these rules, report it privately through **[Security → Report a vulnerability](https://github.com/bila4l4/OptiEleven/security/advisories/new)** (it reaches only the maintainer), or contact [@bila4l4](https://github.com/bila4l4) on GitHub. Reports are handled confidentially. The maintainer may remove comments, lock threads or block people who break these rules, as the Contributor Covenant describes.
